Lambda-fix 0.0.8 - Windows package
==================================

RENUMBERED
----------
This package was published as 1.0.8. It was never a 1.x release - the
project is pre-release software and that numbering claimed a stable
interface it does not have. It is now 0.0.8 on the 0.x line, with the
beta tag starting at 0.1.8. The ZIP is byte-for-byte the same archive;
only its name changed, so its sha256 is unchanged.


WHAT THIS IS
------------
1.0.4's exact 98-file gearbox_addon layout, with only two files changed:
dlls/opfor.dll and MOD_MANIFEST.json.

WHAT CHANGED
------------
The server DLL is now a STOCK Opposing Force server, built from the pinned
halflife-op4-updated tree with exactly one edit. It is not built from bhl-op4.

  stock OP4 server   + Spore Launcher classname fix
  - no BugfixedHL server systems
  - no speedrun core
  - no sv_pushable_fixed_tick_fudge (the stock tree does not have it)
  - no CPushable rewrite, no PushThink
  - no impulse 101 change

func_pushable in this DLL is Valve's code, unmodified.

WHY
---
You confirmed the clean OP4 server you uploaded works, and every build derived
from bhl-op4 did not. Rather than keep guessing at the difference inside a
binary, this package uses the same kind of server you know works.

WHAT YOU LOSE
-------------
This is important, so it is not buried:

  1. The 1.0.4 damage and skill work is NOT in this DLL.
     62 OP4 gSkillData fields and 186 OP4 sk_* cvars were added in the bhl-op4
     tree. A stock OP4 server reads its skill values from gearbox/skill.cfg
     instead, exactly as the original game does. If skill.cfg is present in your
     install, OP4 damage will be normal. If it is missing, damage values will be
     wrong.

  2. No BugfixedHL server-side fixes.
     Whatever BHL fixed on the server is gone in this build.

  3. No speedrun hooks.

The client DLL is unchanged from 1.0.4, so the menu, HUD and CVar client work is
still there.
