Lambda-fix 0.1.4 - Windows package
==================================

RENUMBERED
----------
This package was published as 1.1.4. It was never a 1.x release - the
project is pre-release software and that numbering claimed a stable
interface it does not have. It is now 0.1.4 on the 0.x line, with the
beta tag starting at 0.1.8. The ZIP is byte-for-byte the same archive;
only its name changed, so its sha256 is unchanged.


WHAT YOU ASKED FOR
------------------
"Make the code like my DLL."

That is now done in a stronger sense than before. Previously I only copied
CPushable::Move(). This release compares our whole func_break.cpp against the
working server's func_break.cpp - function by function - and ports every
difference.

WHAT WAS STILL DIFFERENT
------------------------
A token-by-token comparison of every CBreakable/CPushable function found three
things ours was missing:

1. CPushable::DamageDecal      was absent entirely.
   The working server has it: a breakable pushable uses CBreakable's decal,
   a non-breakable one uses CBaseEntity's.

2. CPushable::StopSound        was inside "#if 0" - compiled out.
   The working server compiles it. Now we do too.

3. pSpawnObjects[22]           was missing "weapon_penguin".
   The working server's breakable list ends with weapon_penguin; ours ended at
   weapon_hornetgun. A crates "spawnobject" key of 22 spawned nothing in ours.
   CPenguin.cpp is already in our build, so this was a pure omission.

Also removed: the temporary [pushdbg] logging and the lambda_pushable_debug
cvar from 1.1.1-diag. No diagnostic code is left in the server.

WHAT MATCHES NOW
----------------
Function set is identical, none missing, none extra:

  BreakTouch  DamageDecal  DamageSound  Die  IsBreakable  KeyValue
  MaterialSoundPrecache  MaterialSoundRandom  Move  Precache  Spawn
  StopSound  TakeDamage  Touch  TraceAttack  Use

Move/Use/Touch/Spawn/Precache are identical bar int-vs-bool and comments -
ints are forced by this tree's CBaseEntity, which predates bool overrides.
The logic is the same in every one.

PushThink and FindTouchingEntity: still absent. That stands from 1.1.2.

NIGHT VISION
------------
Unchanged: on = items/flashlight1.wav, off = items/flashlight2.wav.

VERSION
