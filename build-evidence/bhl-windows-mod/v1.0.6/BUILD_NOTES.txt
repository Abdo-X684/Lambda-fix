Lambda-fix 1.0.6 - Windows package
==================================

WHAT THIS IS
------------
1.0.4's exact 98-file gearbox_addon layout with two files touched:
dlls/opfor.dll and MOD_MANIFEST.json. Everything else is byte-identical to
1.0.4.

WHAT 1.0.5 BROKE
----------------
1.0.5 fixed push and pull, and you confirmed that. It also broke object
boosts, and you were right to call it out.

The rewrite drove the box from its own think every frame and, in doing so,
overrode its velocity in two situations where the original code deliberately
did nothing:

1. A player RIDING the box. PushThink assigned the box a horizontal velocity
   from the player every frame, sliding the box out from under the rider. The
   original Move() returned before touching velocity when a player stood on
   the box, and moved it only in water.
2. A player AIRBORNE against a moving box. The box's speed was replaced with
   the player's air speed, which braked it. The original returned early
   unless the box was in water.

It also rewrote the player's own velocity every frame. The original only did
that on a real Touch() contact. Doing it per frame killed jumping and
strafing while in contact, and finished off any boost.

WHAT 1.0.6 DOES
---------------
PushThink now reproduces both guards exactly:

  player riding the box   -> only the water case moves it, then return
  player airborne         -> do nothing unless the box is in water
  otherwise               -> assign box velocity from the player
                             factor 1.0 while USE is held (pull)
                             factor 0.25 while USE is free (push, as before)

The player's velocity is never rewritten from the think. It is still matched
to the box inside Touch(), which is where the original did it.

Velocities are still assigned rather than accumulated, so the framerate
independence from 1.0.5 is kept: sv_pushable_fixed_tick_fudge is not consulted
and the result does not depend on frame rate.
