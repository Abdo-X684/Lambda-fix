Lambda-fix 0.1.0 - Windows package
==================================

RENUMBERED
----------
This package was published as 1.1.0. It was never a 1.x release - the
project is pre-release software and that numbering claimed a stable
interface it does not have. It is now 0.1.0 on the 0.x line, with the
beta tag starting at 0.1.8. The ZIP is byte-for-byte the same archive;

WHAT THIS IS
------------
1.0.4's exact 98-file gearbox_addon layout, with dlls/opfor.dll replaced.
Carries forward everything that worked in 1.0.9 (box movement confirmed by
you in game) and fixes the two things you reported afterwards.

FIX 1 - THE BOOST NOW HAPPENS WHEN YOU RELEASE E
------------------------------------------------
You said: the boost comes while E is held, not when you let go. Correct, and
the cause was my PushThink, not Valve's code.

While +use is held, PlayerUse() calls CPushable::Use() every frame, which
calls Move(player, 0): accumulate the player's velocity, then set the player
to the box's velocity. push = 0, so the MaxSpeed clamp is skipped. That
feedback loop is the object boost, and it is what launches you when the key
is released.

PushThink was ALSO calling Move(player, 1) every frame. push = 1 turns on the
clamp, so on every one of those frames the box was cut back to MaxSpeed. The
box was dragged along at MaxSpeed (that felt like a boost while held) and
there was nothing left to hand back on release.

PushThink now skips the call in exactly two cases:

    player is overlapping AND holding +use          -> Use() already did it, unclamped
    box speed is already above MaxSpeed             -> only the boost does
                                                       this; clamping it would cancel it

Otherwise it is unchanged and still calls the same Move(player, 1) that
Touch() would have made. Move(), Use() and Touch() are untouched.

FIX 2 - NIGHT VISION SOUND
--------------------------
SOUND_FLASHLIGHT_OFF was defined as items/flashlight1.wav, the same file as
SOUND_FLASHLIGHT_ON. Turning the light off replayed the on click.
OP4 dlls/player.h uses items/flashlight2.wav for off; we now match it. Both
are precached in client.cpp, so no other change was needed.
