Lambda-fix 0.0.2 — Windows package
=================================

RENUMBERED
----------
This package was published as 1.0.2. It was never a 1.x release - the
project is pre-release software and that numbering claimed a stable
interface it does not have. It is now 0.0.2 on the 0.x line, with the
beta tag starting at 0.1.8. The ZIP is byte-for-byte the same archive;
only its name changed, so its sha256 is unchanged.


CHANGE FROM 1.0.1
-----------------
1.0.1 shipped gearbox_addon/dlls/ EMPTY and liblist.gam said:
    gamedll "../gearbox/dlls/opfor.dll"
  so the engine loaded the stock 2002 Valve opfor.dll from gearbox/.
  The BHL server was never used.

1.0.2 fixes that:
* gearbox_addon/dlls/opfor.dll  = BHL server (hl.dll from the same build)
* gearbox_addon/cl_dlls/client.dll = BHL client from the same build
* liblist.gam: gamedll "dlls\opfor.dll"   (no ".." path)
* fallback_dir "gearbox" kept: assets only (maps, models, sounds)

CRASH FIX PRESENT
-----------------
COFGonome::GUTS_GRAB now guards m_hEnemy before dereferencing it:
  0xC070B  lea  ecx, [edi+0xf8]    ; &m_hEnemy
  0xC0711  call 0x1CA40            ; EHANDLE -> CBaseEntity*
  0xC0716  test eax, eax           ; NULL check
  0xC0718  je   0xC0EED            ; bail out safely
