WHAT IS DIFFERENT FROM 1.0.1
----------------------------
1.0.1 shipped gearbox_addon/dlls/ EMPTY and pointed liblist.gam at
"../gearbox/dlls/opfor.dll", i.e. the stock 2002 Valve server. The BHL
server was never loaded.

1.0.3 puts the BHL server inside the package:
  gamedll "dlls\opfor.dll"
and keeps fallback_dir "gearbox" for assets only (maps, models, sounds).
No DLL is loaded from gearbox/ any more.

CRASH FIX PRESENT AND VERIFIED IN THIS BINARY
---------------------------------------------
COFGonome::GUTS_GRAB guards m_hEnemy before dereferencing it:

  0xC070B  lea   ecx, [edi+0xF8]   ; &m_hEnemy
  0xC0711  call  0x1CA40           ; EHANDLE -> CBaseEntity*
  0xC0716  test  eax, eax          ; NULL check
  0xC0718  je    0xC0EED           ; bail out safely

GUTS_GRAB is reached from the animation event table at 0xC0F14,
entry index 2 of the COFGonome event list.

WHAT THE USER MUST SUPPLY
-------------------------
gearbox/ must stay next to gearbox_addon/ - the mod reads Valve assets
from it. The server DLL is no longer taken from there.
